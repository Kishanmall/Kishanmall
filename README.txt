Kishan Mall Portfolio
---------------------
VS Code me chalane ke liye:
1. Zip ko extract karo, folder VS Code me kholo (File > Open Folder)
2. "Live Server" extension install karo, index.html pe right-click > Open with Live Server
   (ya seedha index.html ko browser me double-click karke khol sakte ho)

Files: index.html | css/style.css | js/main.js | assets/ (images)
WhatsApp number badalne ke liye index.html me 917705031701 search karke replace karo.
